## 数値照合（架空例）

同一対象期2028年、A本則300,000円、B簡易0円（Bの適用条件は未確認の参考試算）。共有中間予定を123,000円に設定。Bの未確認を確認済みに変えていない。

|月|A中間|B中間|A確定|B確定|A還付|B還付|
|---|---:|---:|---:|---:|---:|---:|
|2028-08|123,000|123,000|0|0|0|0|
|2029-02|0|0|177,000|0|0|0|
|2029-03|0|0|0|0|0|123,000|

Aの精算123,000+177,000=300,000円、Bは123,000−123,000=0円。両案の最終資金差B−Aは300,000円。金額・発生月は画面の棒/数値、月別表、コピー、CSV、印刷で一致。中間なしの例もA確定300,000円/B0円で確認。
