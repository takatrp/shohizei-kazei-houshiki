# 消費税 課税方式判定ツール

本則課税、簡易課税、2割特例、3割特例の概算納付額を比較する静的HTMLツールです。

## 使い方

`index.html` をブラウザで開くか、GitHub Pagesで公開して利用します。

主な入力項目:

- 事業者区分、課税期間
- 税率モード（現行の軽8％、または食料品等1％の試算）
- 基準期間の課税売上高（1,000万円・5,000万円要件を自動判定）
- 特定期間の課税売上高・給与等支払額（2割特例・3割特例の要件を自動判定）
- 簡易課税の事業区分ごとの10%売上・軽8％売上
- インボイスあり課税仕入
- 免税事業者からの課税仕入（80%・70%・50%・30%・0%の控除割合別）
- 本則課税用の仕入税額控除率と個別調整額
- 別モードでの同額前提4期見通し

## 注意

このツールは方式比較のための概算です。制度時点は2026年6月10日時点（国税庁 令和8年度税制改正特集ベース）です。食料品等1％モードは、未施行の議論段階にある税率変更を想定した試算であり、現行申告用の判定ではありません。4期見通しは同額前提の別モードで、3期目以降の基準期間売上高には現在の課税売上合計を税抜換算して反映します。免税事業者仕入の控除割合は、2期目以降、各期の開始日に応じた割合へ置き換えて本則税額を再計算します。2期目の基準期間売上高は未入力のため、現在入力した基準期間売上高を仮置きします。個人事業者で課税期間が暦年（1月1日から12月31日）でない場合、課税期間短縮等に該当するものとして2割特例・3割特例は候補から外します。簡易課税は原則2年間の継続適用にも注意してください。本則の仕入控除割合は課税売上割合・控除方式によって変わるため、100%のまま使うと本則が過大に有利に出る場合があります。申告時は帳簿、届出状況、国税庁資料、個別事情を確認してください。
