再レビューでは、手入力とCSV反映のどちらも現在の課税区分別行を申告書計算へ渡すよう統一した。CSVの無変更フォーカス移動では取込由来を保ち、行追加・削除・金額変更後は現在行から再計算する。簡易課税・2割・3割特例の現行制度分にも同じ段階の端数処理を適用し、4期の各期も端数処理後の額を累計する。対象期とCSV取引日が一致しない場合は参考前提を残し、必要な区分・非課税売上の有無・仕入用途等を復元できない場合は概算額に戻さず未算定理由を示す。食品1％の未施行試算は従来の概算経路を維持する。

## 仮定・仮除外後の参考額（追加検証）

申告書再現の完了状態と参考額の算定可否を分離した。税率10％を仮定した匿名仕入110,000円を含む例では、現在行からの本則税額90,000円を端数処理後の参考額とし、厳密再現は未完了とする。金額不明の仕入1明細を明示的に仮除外した例では、残る売上1,100,000円から本則参考額100,000円を示す。仮除外の税額影響は算定せず、件数と金額不明を通常出力・印刷前提へ残す。仕入110,000円へ正式補正・反映すれば厳密計算90,000円へ戻り、プレビューだけ・反映取消しでは現在の参考額を変えない。簡易・2割・3割と4期累計も同じ現在行の端数処理後の参考額を使う。未処理・未対応・必須額不足は引き続き未算定とする。
