# r36.0.1 計算概要の税率合計表示修正

2026-10-24 JST。起点main `11c075eb7e5cf3eccb179e599692c784e10aef09` のr36.0から、計算結果の説明表示だけを修正する。税計算エンジン、保存形式、入力項目・画面遷移は変更しない。r36.0で記録した政策試算・未対応範囲の制限は引き継ぐ。

## 問題と修正

現行一般課税で8％・10％売上が混在すると、概要式の先頭と返還が付表1-3の10％欄②B・⑤Bだけを参照し、両税率合計の正しい税額結果と式が一致しなかった。第一表の②（売上税額合計）・④（控除）・⑤（返還合計）をそのまま使い、同じ計算結果の説明を画面・コピー・CSV・印刷へ渡す。税額の表示層再計算は追加しない。

詳細過程にも軽減8％の課税標準・売上国税・返還を示し、差引式は同じ第一表合計を使用する。既存エンジンに合わせ、詳細説明の納付/還付の端数単位も区別する。

税込4金額10,800,000 / 11,000,000 / 5,400,000 / 5,500,000円の場合、国税売上624,000+780,000=1,404,000円、控除312,000+390,000=702,000円。正しい概要は次のとおり。

`第一表② 1,404,000円 − ④ 702,000円 − ⑤ 0円 → 国税 702,000円 ＋ 地方税 198,000円`

年税額900,000円は改修前後で同じ。8％のみ400,000円、10％のみ500,000円、両税率の返品あり720,000円、混合仕入の還付−720,000円も独立手計算と照合する。制度要件・算式を新設する修正ではない。
