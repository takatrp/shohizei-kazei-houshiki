# r31 STEP4「資金繰りへの影響」検証記録（2026-09-25）

## 範囲と正本

画面の4段階は「事業者・対象期間」「金額の入力」「税額の比較」「資金繰りへの影響」。旧保存データとの互換のため内部IDは1→2→4→5であり、旧ID4のSTEP3を改名・削除しない。STEP4は食品1％の未施行政策試算だけで表示し、同一課税方式の現行税率／1％を比較する。税額はSTEP3の `buildCurrentRateComparison(calc)` による同一結果から取得し、制度判定・端数処理を再実装しない。税込売上・仕入の差額も同じ `calc` と現行税率側 `comparison.current` から取り、表示円へ一度だけ丸める。STEP4の月次計算は税額を変更しない。

対象は指定した一課税期間の対象食品取引と、その回収・支払・当期税金の予定まで。期首資金、前期からの持越し、翌期の新規取引、消費税以外の費用・借入等は含めない。最大一時資金減少は0円起点の月末累積最小値から算定し、借入必要額や資金不足の確定額ではない。税金未確認なら税金イベント・税金込みの最大減少・精算後差額を未算定にする。中間納付は両案で別々に予定し、各案の当期税額から中間納付予定を引いた残額のみを確定納付、超過分を還付入金に置く。未納・実際の還付時期は対象外。

CSVの月別集計は補正・仮除外後の課税区分・税率・事業区分・用途・割合・年月・正負の合計だけを使い、元の科目・摘要・顧客名・仕訳行番号は保存しない。月次は年額の配分形状にすぎず、現在の行入力とSTEP3が金額の正本。元資料期間・全月網羅を確認できない、日付不明、区分不一致、月別差引0などは対象日数で均等配分し、理由を表示する。手修正後は元CSV構成比が使える同一区分に限って参考利用する。

## 留保

税金予定、決済月ずれ、元資料期間・全月網羅は担当者の確認入力であり、申告書や銀行入出金から自動確定しない。CSV月別構成比は取引金額の月次形状であり、食品商品別や実際の入出金日ではない。元資料の範囲・未確認・仮定・補正・除外の表示は、最終税額や政策施行の確定を意味しない。食品1％政策が未施行である前提を維持する。後日の制度変更や実務適用は本作業の検証範囲外。
