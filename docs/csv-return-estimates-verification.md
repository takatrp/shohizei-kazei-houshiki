# r36.0.5 CSV概算継続修正の検証

2026-10-25 JST。起点は公開main `6871e7d28a85283ce41499e945159abb4fc7c09f`（r36.0.4）。申告書の厳密再現と、未確認の仮定を含む参考概算を区別する。

## 修正

- CSVの8％集約行を、対応する匿名の日別・月別の符号付き内訳から通常取引と返品・調整へ分離する。食品1％の予測は通常部分にだけ適用し、調整は元税率で一度だけ計上する。内訳が対応しない行は差引純額を代理とする注意付き概算とし、負額を0円化しない。
- 明示1％の返品でも元8％・10％が既知なら優先する。元免税と明示された売上返還は課税売上の返還控除へ含めない。原行・原本は書き換えない。
- 一般の参考概算と、照合済み実前期CSVによる中間特例再計算の証拠判定を分離する。元8％・10％の返還を「確認済み1％実績」へ昇格させない。
- 仕入の正負を3用途で保持する。部分控除でも負の共通・非課税対応額を切り捨てない。用途不明は共通対応、割合不明は控除なしの当期概算とし、仮定を表示する。CSVの日付・割合の不一致は記載値を使った参考概算とし、照合済みにはしない。
- 負の食品以外売上基礎は、簡易の通常計算・特例の負担割合を符号付きで使う参考概算を表示する。簡易の75％特例はこの場合に採用しない。元取引の申告方法等は未照合と表示する。厳密な申告書再現エンジンの判定は維持する。
- 将来期は分離後の通常・調整を同じ増減率で予測し、既知の元税率・元免税状態も保持する。割合・用途未確認の明示1％仕入も注意付きで引き継ぐ。
- 共通注意を画面・コピー・CSV・印刷・STEP4へ伝え、原行と匿名の元内訳を保存復元する。通常の必須入力・保存キー・保存形式は増やさない。

## 匿名検証

- Node標準テスト991件、静的build、`git diff --check`。
- `scripts/csv-return-estimates-browser.cjs`：匿名CSVの実ファイル入力、現行／食品切替、保存・リロード、手入力0円、純額0円、部分控除の負仕入（3用途）、既知の元税率と元免税、割合・日付・用途未確認、将来期増減、当期／4期概算、STEP4の画面・コピー・CSV・印刷を11群で確認。外部通信を遮断した新規ブラウザコンテキストを使用する。
- `scripts/continuation-browser-review.cjs`：既存12群の回帰を確認。
- 通常10,800円、調整−1,080円の架空8％取引は、通常分の1％予測と元8％調整を合わせて税込9,020円・税20円。同じ構成を＋10％にすると税込9,922円・税22円。全純額をまとめて1％へ置換する結果と区別する。
- 初回と追レビューで見つかった負仕入上限、既知元税率、用途仮定、将来期の内訳・元免税・割合未入力、実前期証拠の厳密判定への波及を修正して回帰に含めた。最終独立レビューは追試39件成功、公開を妨げる重大な未解決なし。PRではunit・build・匿名ブラウザのCIも確認する。

## 未実施・制約

実顧客CSVと元のエラー画像は、このクラウド環境での正式取得が失敗したため読取り・実画像確認・最終差分での再検証を行えていない。匿名再現と回帰の成功を、当該実CSVの成功とは扱わない。実顧客CSV・画像・固有名・実額はリポジトリ、fixture、スクリーンショット、CIへ含めていない。

制度の成立や正式な申告税額、未確認の届出・適用可否を確定する変更ではない。公開反映と公開URLでの実操作は、PR・Pages実行と公開後の作業報告に別途記録する。
