# FX4クラウドの仕訳帳CSV

従来の借方・貸方別のTKC仕訳帳CSVに加え、FX4クラウドの共通列形式を読み込めます。ファイルはブラウザ内で解析します。

- 共通列 `税`、`業`、`取引金額`、`税率`、`内、消費税等`、`控` を借方・貸方別の内部形式へ変換します。科目コード・科目名、`月日`、`税抜き金額`、`取引年月日` も必要です。列順や追加列は問いません。
- `取引金額` は税込金額として一度だけ使用します。`内、消費税等` や `税抜き金額` を加算しません。負数は保持し、売上・仕入の返還は課税区分の貸借方向で差し引きます。
- 税率は `10.0%A`・`10.0%`、`軽 8.0%A`・`軽 8.0%` などに対応します。標準8％や未知の記号を軽減8％に読み替えません。不明な税率・控除割合・金額は既存の補正画面へ残します。
- 年のない表示用の `月日` から年を推定せず、8桁の `取引年月日` を使用します。不正日付や合計行を含むCSVはエラーにして、合計の重複加算を防ぎます。仕訳明細のみを出力してください。正当な同額取引を消さないため、同じ内容の行を自動で重複削除しません。
- `業` が空欄の場合、売上科目の事業区分を確認する既存の手順が必要です。
- 有価証券等の譲渡・輸入課税仕入れなど、既存ツールが自動集計できない区分は補正・確認対象に残ります。未知の共通課税区分は貸借方向を推定せず、行番号と区分を表示して停止します。未確認の明細を黙って除外して取込完了にはしません。
- UTF-8（BOMあり／なし）とShift_JISに対応します。引用符、カンマ、引用符内改行の処理は従来形式と共通です。
- 試験機能の現預金実績集計にも同じ正規化を使用します。共通税込金額を借方・貸方それぞれの仕訳金額として扱います。

課税区分の意味は従来ツールと共通です。TKC公式の[FXクラウドAPI資料](https://www.tkc.jp/api/fxcloud/dev/)でも、課税区分・事業区分・取引金額・消費税額・軽減税率がそれぞれ独立した項目として定義されています。CSV独自の表示表記は出力された列を正規化します。

回帰テストは `node --test tests/fx4-csv.test.js`、全体検証は `npm test` と `npm run build` です。テストの明細はすべて架空のものです。顧客CSV・画面PDFをリポジトリに追加しないでください。
