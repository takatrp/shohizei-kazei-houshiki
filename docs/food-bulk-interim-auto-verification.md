# r32 食品対象額一括転記・中間納付自動設定 検証記録

確認日：2026-09-25。対象はローカルの作業ツリー。コミット・公開は行っていない。実顧客CSV/PDFは使用・収録せず、画面確認には匿名の架空金額・架空仕訳だけを使用した。

## 実装範囲と計算根拠

- STEP2の売上表・仕入表に各1個の「全て食品1％対象とする」を配置。現在行モデルの軽減8％・対象TKC区分・入力済み税込金額だけを同じ行の食品内数へコピーする。10％、非課税、未入力・不正額、CSVの1％実績サイドカーは変更しない。入力済み0円を含む上書きは操作につき一度確認し、キャンセルなら全行を維持する。対象なしはボタンを無効化する。食品分類・返品元取引の確認状態は変更しない。元CSVの月別額・通常取引／返還の区別は保持する。
- STEP4の標準自動モードは、同じ前期国税額を両案へ適用する。標準の代理値はSTEP3「現行税率（8％維持）・選択方式」の**現在入力から計算した国税内訳**であり、前期実績ではない。概算と明示し、STEP3合計額から確定国税を逆算しない。前期申告書がある場合は国税分・中間納付控除前の額と期間を入力できる。別前期仮定は高度設定で明示選択する。
- 直前期国税 `N`、直前期月数 `P`、各中間対象期間月数 `K` について、回数は国税分のみで判定。各回国税は `floor(N×K/P/100)×100`、地方税は `floor(各回国税×22/78/100)×100`。国税・地方税の100円未満を別々に切り捨てる。0・1・3・11回を対象に、同一納付日の複数申告は回次を残し、月次の資金イベントでは合算する。
- 中間対象期間から原則期限を日付で算出し、土日・祝休日・12/29～1/3を翌開庁日へ繰り延べた**後**に納付月へ割り当てる。2026・2027年の公表祝日を固定確認し、未公表年は暫定予定として警告する。法人の延長は消費税の申告期限延長特例のみを対象とする。
- STEP4年税額 `T` はSTEP3と同じスナップショットを使用。中間納付 `M` と確定差額 `T−M`（負数は還付）を別イベントにし、`M+(T−M)=T` を保つ。還付入金月は別途手入力で、期限から自動確定しない。食品1％に関する中間申告特例・仮決算は通常の前期実績方式へ混入しない。

根拠：[国税庁 No.6609 中間申告の方法](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6609.htm)、[国税庁 消費税法基本通達15](https://www.nta.go.jp/law/tsutatsu/kihon/shohi/15/01.htm)、[国税庁 中間申告分の納期限](https://www.nta.go.jp/taxes/nozei/nofu/24200038/01.htm)、[国税庁 納期限と休日](https://www.nta.go.jp/law/tsutatsu/kihon/tsusoku/01/03/10.htm)、[内閣府 国民の祝日](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)。政策試算の食品1％条件は既存の未施行前提であり、現行確定法として表示しない。

## 未対応・要確認

- 当期が通常12か月以外、月数を法令に基づき確定できない前期（月途中29～31日開始等）、課税期間短縮特例あり、前期税額の途中変更、災害延長、合併・相続等の特殊事情は通常自動予定を完成させない。手入力または資料確認が必要。
- 2028年以降の祝日は未公表なら暫定予定。公表後に期限を再確認する。振替納税日・任意中間申告・食品1％の特例/仮決算は自動適用しない。
- STEP3代理の国税内訳は対象期の現在入力からの**概算**であり、実際の前期申告書の国税欄ではない。別前期の変更案をSTEP3政策額から78％概算按分する高度設定は、国・地方の厳密な申告書内訳を保証しない。調整額等がある場合は自動算出を停止し、前期国税を入力する。
- CSVの税率8％が現行の軽減8％か旧標準8％かの原資料判別はCSVの課税区分・軽減税率フラグと対象期間の元帳照合が必要。今回の一括転記は既存行モデルで「軽減8％」と認識された行に限る。元取引の食品分類を確定した扱いにはしない。
