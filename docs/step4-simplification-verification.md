# r35.2 STEP4 資金増減基準の簡素化・検証記録

## 変更範囲と正本

対象はSTEP4の表示用共通ベースと画面・出力。`tax-engine.js`、`tax-return-engine.js`、`journal-csv.js`、`cashflow-engine.js`、`cashflow-adapter.js`、`method-cashflow-adapter.js` は変更していない。A/Bの中間納付・確定納付・還付、B−Aの `net` / `cumulative` は既存STEP4の結果を正本にする。

通常画面は「表示用参考額（従来方式）」「手入力した月別金額」の2択で、前者が初期値。従来のCSV現預金実績は詳細設定の試験機能に移し、解析コードと保存済み選択を維持する。参考額は実際の営業収支を表すものではない。手入力は千円単位の符号付き金額（小数第3位までで1円精度）を円へ変換する。対象期の全月で空欄は未入力、`0` は明示0円。対象期外の精算月は共通ベース0円とするが、対象期変更で以前の値を流用しない。

両モードとも同じ `buildPanelData()` に共通ベースを渡し、同じ `baseSource`・グラフ・表を使う。A/Bの当月値と税イベントは同じ計算経路で生成し、B−A月次・累積を既存エンジンと円単位で照合する。不一致、入力不足はパネル未算定にし、STEP3税額を変更しない。食品1％の方式比較で手入力の共通ベースは選択中の前提に沿う値として扱い、8％実績と断定して食品差額を重ねない。CSV試験機能の確認済み8％実績だけ、従来どおり食品取引差をA/B共通に重ねる。
