# r36.0 の追加操作

通常導線は「事業者・対象期間 → 金額入力 → 税額比較 → 資金繰り」の4ステップです。今回の追加機能を選ぶことは通常比較の必須条件ではありません。

1. 手入力のSTEP2では業種型と、税込の食品売上・その他売上・食品仕入・その他課税仕入経費から始められます。4金額が揃うと通常の詳細行へ自動反映します。新聞・非課税・輸出・返品・用途や控除割合の違いがある時は詳細を開いて修正してください。詳細・CSVの内訳がある案件では要約だけを表示し、4金額で上書きしません。
2. 食品1％は改正案に基づく政策試算です。食品額の手修正、0円、空欄は維持します。同じ元CSVの正式期間・全月網羅・現在行の一致を確認できれば対象期間額へ月別構成を優先し、不足部分だけ日数按分へ戻します。採用根拠を前提と出力に残します。
3. STEP3の当期比較の下で「措置終了後まで比較」を開けます。将来期は当期構成を引き継ぐ仮定です。変わる期だけ売上・仕入増減、設備投資を入力できます。基準期間や特定期間・届出が不明な方式は可否未確認とし、税額と分けます。単年の最安方式を自動的な最適経路とは呼びません。
4. STEP4の通常中間納付の欄で食品特例と比較できます。実際の前期・正確な方式・食品内訳・控除関係が必要です。STEP3代理額は実前期に使いません。補足額は実前期に結び付け、期間が変わると利用しません。A/B別に特例利用予定を指定するまで通常方式を維持し、手入力予定は上書きしません。
5. 現在の申告方式が「現在は免税」の案件だけ、対象期の納税義務と、免税維持・課税選択・登録経由を確認できます。登録申請の提出済みと登録済みも分けます。期中登録では登録後の取引だけを比較します。同じ元CSVの正式期間・全月網羅と現在行が一致する時は日別実額を優先し、旧保存の月額だけでも月境界なら実額集計します。それ以外は理由付き日数概算へ戻ります。免税の継続や復帰は基準期間等・登録・選択の拘束・資産制限によるため、単なる0円の第5方式にはしません。
6. 保存は従来の「この端末に保存」が有効な時だけです。保存なしでは追加入力も保存しません。前期補足・将来仮定は対象期間に結び付けます。元CSV原文、摘要、取引先を追加保存・送信しません。日付別の匿名分類・金額は既存の明示保存設定に従って保存し、実額集計の再読込に使います。

食品制度の成立・正式様式や輸入の中間特例細目は一次資料の再確認が必要です。元取引の税率・課税状態等が分かる返品は対応範囲を算定し、不明な内訳だけ要確認にします。棚卸・固定資産の移行調整は現行制度自体が未確定なのではなく、明細・取得履歴・複数年割合等が必要です。本ツールの課税選択税額はその詳細調整前の概算で、還付額だけで推奨しません。資料と算式の不足を分けた [残件分類](continuation-final-review.md) を参照してください。旧版の保存案件は税額に影響する変更があるため再試算してください。詳しくは [一次資料](continuation-primary-sources.md) と [検証記録](continuation-verification.md) を参照してください。
