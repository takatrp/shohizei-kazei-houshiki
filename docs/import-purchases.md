# 輸入55・65・75の概算対応

## 分類と入力

輸入55（課税売上対応）・65（非課税売上対応）・75（共通対応）を国内税込仕入れへ混ぜません。摘要の地方消費税・地方税を先に識別し、地方税以外の消費税・国税、関税、仕入・本体等を分類候補にします。税額0・税抜額＝取引額の行も本体候補です。関税と消費税の併記等で判断できない行は未分類のまま残します。摘要の文言で金額符号を反転せず、元CSVの符号を尊重します。

CSVからは用途・税率・税種ごとの集計行へまとめ、元明細数を保持します。毎明細を手作業で指定する必要はありません。候補の合計を確認し、未分類は「未分類に一括適用」で補正できます。必要なら集計行を分割・金額修正してください。追加CSV列「輸入区分」に本体/関税/国税/地方税/税合計（goods/duty/national/local/taxTotal）が明示されていれば、その区分を優先します。

## 国税と地方税の扱い

国税実額を優先し、付表2-3⑮の課税貨物に係る消費税額へ加えます。全額控除条件下は3用途すべて、個別対応は55の国税＋75の国税×課税売上割合、一括比例は3用途の国税合計×割合です。短期の5億円判定は課税売上を年換算しますが、輸入国税自体を年換算しません。簡易課税・2割特例・3割特例へ実額の追加控除はしません。関税・輸入地方税を国税控除へ加えません。

概算の補完は次の前提を表示します。

- 国地方税合計しかない行：対応する8％・10％の国税78％・地方税22％で円単位四捨五入。税関で各税を端数処理した実額とは差が出ます。
- 国税または地方税のみ：不足側を22/78または78/22で概算。実額が入力されれば実額を優先します。
- 税額のない本体・関税：選択した場合のみ、本体＋関税をCIF等課税価格の代理として率を乗じます。国内税込額の10/110・8/108は使いません。その他内国税・為替・税関端数等は未反映です。この選択は解除できます。

摘要候補・比率補完・課税価格代理がある本則結果は、法定申告額の厳密再現ではなく参考算定です。空欄・不正金額・未分類は0円確定とせず、補正や概算前提の確認が必要です。税合計行と同じ税の別行を重複して入力しないでください。

## 食品1％政策試算と資金繰り

輸入軽減8％は食品対象割合100％を初期値とし、必要なら0〜100％へ修正できます。課税価格・数量・本体・関税を固定し、1％対象期間の対象国税・地方税を8分の1とする概算です。期間を日数按分する設定では対象期間割合も反映します。将来の輸入許可書等の税額、為替、数量、関税・課税価格の変動や税関の端数を予測したものではありません。

資金CSVの輸入時支出は通常の支出に一度だけ残し、年税額の納付・還付除外候補にはしません。政策側では輸入税の支払差額だけを月別の日数で配分し、通常の支払遅延設定を使う概算です。実際の輸入本体・関税・税の支出へ再加算しません。一般の食品仕入れ差額と輸入税差額を別に作り、各一度だけ反映します。

## 課税期間の確認

法人の1％政策試算では、比較対象課税期間が2027-04-01～2029-03-31と1日も重ならない場合、大きな警告を表示して画面進行・計算・出力・CSV反映を停止します。両端を含むため、2027-04-01または2029-03-31の1日だけでも重なればこの条件では禁止しません。空欄・無効日付・逆順も日付修正まで停止します。現行税率・個人にはこの法人向け期間制限を適用しません。これはユーザー指定の仮定試算期間で、制度の成立を断定するものではありません。

1％試算で暦の1年以外なら「中間納付が自動計算されませんがよろしいですか？」と確認します。キャンセル時は計算・保存せず直前の有効期間とモードへ戻し、承認後も自動中間納付は未算定です。閏日・月末を考慮し365日固定にはしません。
